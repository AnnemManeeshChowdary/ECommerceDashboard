# E-Commerce Sales Analytics Dashboard

## Overview

The E-Commerce Sales Analytics Dashboard is an interactive Power BI project designed to analyze sales performance, customer behavior, product trends, and business growth metrics. The dashboard transforms raw sales data into actionable insights that support data-driven decision-making.

This project helps stakeholders monitor key performance indicators (KPIs), identify revenue opportunities, and understand customer purchasing patterns.

---

## Problem Statement

E-commerce businesses generate large volumes of transactional data, making it difficult to quickly identify sales trends, top-performing products, customer preferences, and profitability drivers.

This dashboard addresses these challenges by providing a centralized view of sales performance and business metrics through interactive visualizations.

---

## Objectives

* Analyze overall sales performance.
